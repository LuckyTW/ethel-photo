# 말씀 사진관 — 시냇가에셀나무교회

> 예배에 오신 날, **사진과 말씀을 한 장에** 담아 그 자리에서 인쇄해 드리는 교회 키오스크

태블릿으로 사진을 찍으면 성경 말씀과 합성해 감열 프린터로 즉석 출력합니다.
**서버도, 계정도, API 키도, 비용도 필요 없습니다.** 사진은 전송되지 않고 그 기기 안에만 남습니다.

## 어떤 기기에서 인쇄되나요

사진 찍기·카드 만들기·저장·공유는 **어느 기기 어느 브라우저에서나** 됩니다.
갈리는 건 **블루투스 인쇄** 하나뿐입니다.

| 기기 | 브라우저 | 인쇄 |
|---|---|---|
| 안드로이드 태블릿·폰 | 크롬 | ✅ **운영 권장** |
| 맥북 · 윈도우 PC | 크롬 / 엣지 | ✅ |
| **아이패드 · 아이폰** | **Bluefy** (무료, 앱스토어) | ✅ |
| 아이패드 · 아이폰 | 사파리 · 크롬 · 엣지 | ❌ |
| 맥북 | 사파리 | ❌ |

### 아이패드·아이폰에서 인쇄하기

애플은 사파리에 블루투스(Web Bluetooth)를 허용하지 않고, **앱스토어 규정상 아이폰용 크롬·엣지도
사파리와 같은 엔진을 쓰도록 강제**되어 있어 브라우저를 바꿔도 소용이 없습니다.
이 앱의 한계가 아니라 애플의 정책입니다.

해결책은 **자체 블루투스 기능을 갖춘 브라우저 앱**으로 여는 것입니다:

1. 아이패드에서 위 주소를 열면 상단에 안내 배너가 뜹니다 → **[📋 주소 복사]**
2. **[Bluefy 받기]** → 앱스토어에서 무료 설치 ([Bluefy – Web BLE Browser](https://apps.apple.com/app/id1492822055))
3. Bluefy를 열고 주소창에 붙여넣기 → **그 뒤로는 안드로이드와 똑같이 인쇄됩니다**
4. Bluefy에서도 홈 화면에 추가해 키오스크로 쓸 수 있습니다

> 배너는 블루투스를 못 쓰는 애플 기기에서만 뜹니다. Bluefy로 열면 저절로 사라집니다.
> (브라우저 이름이 아니라 **블루투스가 실제로 되는지**를 보고 판단하기 때문입니다.)

인쇄 앱을 따로 깔기 어렵다면, 사파리에서 **[📤 공유/저장]**으로 카드 이미지를 남겨
다른 기기에서 인쇄하거나 사진으로 간직해도 됩니다.

## 처음 설치하기 (5분)

1. 태블릿/폰에서 위 주소를 엽니다 (안드로이드는 **크롬**, 아이패드는 **Bluefy**)
2. 메뉴 → **홈 화면에 추가** → 전체화면 키오스크 완성
3. ⚙ 설정에서 **교회 이름·하단 문구**를 확인합니다 (설정은 그 기기에만 저장됩니다)
4. 프린터 전원을 켜고 **[🖨 인쇄하기]** → 블루투스 기기 선택창에서 `GB`/`GT`/`MX`/`YT`/`SC`로 시작하는 이름을 고릅니다. 한 번 연결하면 계속 유지됩니다

### 준비물 (총 2~3만원대)

| 품목 | 비고 |
|---|---|
| 감열 프린터 | "고양이 프린터"로 검색 — GB/GT/YT/MX/SC 계열 (SC05 실사용 검증) |
| 감열지 롤 | **57mm 폭**. 오래 보관하려면 고보존(long-life) 감열지 권장 |
| 태블릿/폰 | 안드로이드는 크롬, 아이패드는 Bluefy (위 표 참고) |

> **구매 전 확인**: 겉모양이 같아도 칩셋이 다릅니다. 브랜드 제품(PeriPage/Paperang)은 독자 프로토콜로
> 비호환이고, 영수증형(PT-210 등)은 블루투스 클래식이라 연결 자체가 안 됩니다.
> 판매자에게 **"블루투스 페어링 시 뜨는 기기 이름"**을 물어보세요.

## 평소 운영 (교회 비치용)

**관리할 것은 두 가지뿐입니다 — 충전, 그리고 감열지 롤 교체.**

1. 프린터·태블릿 **충전**
2. 감열지 롤 교체 시 **인쇄면 방향 주의** (거꾸로 넣으면 연결은 되는데 백지가 나옵니다)
3. 인쇄가 갑자기 안 되면 → 프린터 전원 버튼으로 **절전 해제** 후 다시 [인쇄하기]
4. 촬영 원칙 → **찍히는 분이 밝은 쪽(창문·조명)을 바라보게**
5. 촬영이 부담스러운 분께는 **[사진 없이 카드만]** — 성함과 말씀만 인쇄됩니다

### ⚙ 설정에서 바꿀 수 있는 것
- **교회 이름** (카드 상단) · **하단 문구**
- **인쇄 진하기** — 흐리면 올리고, 사진이 뭉개지면 내립니다
- **사진 밝기 보정 / 선명도**
- 진단용: 테스트 인쇄, 용지 이송 테스트, 방식 B 인쇄, 로그 보기

## 기능

- **페이지 내 카메라** — 전면/후면 전환, 줌, 3초 타이머, 카메라 앱 폴백
- **사진 보정** — 지역 적응 명암 보정(조명 맵 기반, 역광에서도 얼굴이 살아남) → 언샤프 마스크 선명화 → 플로이드-스타인버그 디더링
- **✨ 곱게** — 피부결을 부드럽게 하고 톤을 살짝 올립니다
- **말씀** — 현재 요한일서 4:19 한 구절 고정 / 🙏 **기도제목 직접 입력**
- **컬러 카드** — 인쇄용 흑백과 별개로 컬러 PNG 저장·공유
- **🖼 갤러리** — 만든 카드가 기기 안(IndexedDB)에 남습니다. 서버 전송 없음
- **🎉 효과** — 사진에 장식 얹기
- 카드 최상단에 **교회 로고 인쇄**

## 로고 교체

다른 교회·모임에서 쓰려면 로고만 바꾸면 됩니다.

1. `assets/logo.png`를 새 로고로 교체 (**단색·투명 배경**이 감열 인쇄에 가장 잘 나옵니다)
2. 그 이미지의 알파 채널을 그레이스케일 PNG(마스크)로 만들어 base64로 인코딩
3. `index.html`의 `const LOGO_SRC = 'data:image/png;base64,…'` 값을 교체
4. 색을 바꾸려면 같은 파일의 `logoCanvas()` 안 `p[i]=0; p[i+1]=90; p[i+2]=48;` (RGB) 수정

> **왜 파일이 아니라 문자열로 넣나요?**
> 인쇄용 흑백 변환은 캔버스에서 픽셀을 직접 읽습니다(`getImageData`). 외부 이미지 파일을
> `file://`이나 다른 출처에서 불러오면 캔버스가 오염(tainted)되어 이 읽기가 보안 예외로 실패합니다.
> data URI는 같은 출처로 취급되어 어디서 열어도 안전합니다.

로고가 뭉개지거나 너무 옅으면 `logoCanvas()`의 임계값(`m > 110`)이나 `LOGO_W`(기본 96px)를 조정하세요.

## 문구·말씀 바꾸기

- **말씀**: `index.html`의 `const VERSES = [ ["본문", "출처"], … ]`
- 기본 교회명·하단 문구: 같은 파일 `const cfg` 의 기본값 (기기별 설정이 우선합니다)

### 지금은 한 구절 고정입니다

교회 요청으로 **"우리가 사랑함은 그가 먼저 우리를 사랑하셨음이니라" — 요한일서 4:19**
한 구절만 인쇄됩니다. 기존 말씀 100개는 지우지 않고 `VERSES` 바로 아래에 **주석으로 보관**돼 있습니다.

**다시 여러 말씀에서 무작위로 뽑고 싶다면** — `index.html`에서 3단계:

1. `VERSES` 아래 `지난 말씀 풀(100개)` 주석을 풀어 100줄을 배열 안으로 되돌립니다
2. `function pickVerse(){ return 0; }` → `return Math.floor(Math.random()*VERSES.length);`
3. `🍀 다른 말씀 뽑기` 버튼 관련 주석 3곳(버튼 HTML · 표시 제어 · 클릭 핸들러)을 풉니다

> 말씀을 뽑는 시점이 여러 곳(첫 화면·촬영 후·사진 업로드 후·사진 없이 카드)이라
> `pickVerse()` 함수 하나로 모아 뒀습니다. 2번만 고치면 네 곳이 한꺼번에 바뀝니다.
> 3번을 빼먹으면 눌러도 말씀이 안 바뀌는 버튼이 남으니 함께 푸세요.

## 개발

빌드 도구가 없습니다. 파일을 열어 고치고 저장하면 끝입니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

`file://`로 직접 열어도 대부분 동작하지만, 카메라(`getUserMedia`)와 블루투스는
보안 컨텍스트가 필요하므로 로컬 서버 또는 HTTPS로 여세요.

## 스택

단일 HTML + Vanilla JS · Web Bluetooth API (감열 프린터 직접 제어 — 안드로이드·데스크톱은 앱 불필요) ·
Canvas 2D (보정·디더링·카드 합성) · IndexedDB (기기 내 갤러리) · GitHub Pages

프린터 프로토콜: `0x51 0x78` 프레임 + CRC8, 384px 행 단위 비트맵(LSB 우선), 에너지/급지 제어
